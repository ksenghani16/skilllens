SkillLens

Paste two versions of a skill (instructions for an AI). SkillLens finds what got worse, explains why, and proves it.

How it works, in plain words
  1. Test: every test case is given to the old skill and the new skill, several times each, and each answer is checked.
  2. Compare: a case counts as worse only if it passes much less often with the new skill. One random slip is ignored.
  3. Find the changes: the lines that differ are numbered c1, c2, c3…
  4. Ask the AI: a model guesses which changed line caused the problem. Code double-checks that its answer is consistent.
  5. Prove it: code puts back only that line and re-runs the failing cases. If they recover, the cause is confirmed. If not, it is rejected.
  6. Backup search: if nothing was confirmed, every changed line is tried on its own.

Each row is a message to give the skill and the answer it should produce. You can write them yourself or let the AI draft them.

The AI only writes the messages. The expected answers are what the old skill answered the same way every time, so the test means “the new skill should behave like the old one”. Read the expected answers: if the old skill was wrong somewhere, that mistake is locked in. Works best for short, fixed-format answers.
